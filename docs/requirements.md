# 요구사항 (기준 문서)

요구사항·성공 기준의 기준 문서는 조원이 작성한 **「프로젝트 요구사항 최종」(외환·무역 심사 AI 갱신 검증·승인·감시 운영 체계)** 입니다.
원본 파일(또는 링크)을 이 폴더에 함께 올려 주세요.

## 요약

- **시연 시나리오:** S1 변조·손상 파일 차단 / S2 정상 리스트 영향 확인·승인·반려 / S3 리스트 반영·자동 복구 / S4 모델 canary / S5 회귀 모델 차단 / S6 과거 판정 재현
- **구현 순서 (11/12 변경, [결정 0005](decisions/0005-model-path-first.md)):** ① 정상 모델로 **S4·S6**을 끝까지 → ② 모델 변형 시나리오 **S1·S5** → ③ 리스트 갱신 **S2·S3** 순서로 만든다. 빠지는 요구사항은 없고 순서만 바뀐다
- **모듈:** M1 반입 검증 · M2 릴리스 관리 · M3 검증 · M4 배포·서빙 · M5 모니터링 · M6 샘플 심사 서비스 · M7 공통 데이터 · M8 운영 화면 · M9 테스트 도구
- **요구사항 ID:** ING(반입) · REL(릴리스 관리) · VAL(검증) · DEP(배포) · MON(모니터링) · SVC(샘플 심사) · DAT(데이터) · UI(운영 화면) · TST(테스트 도구)
- **우선순위:** P0 = 빼면 S1~S6 중 하나라도 성립하지 않음, P1 = 시연 진행·확인을 도움
- **회의 안건:** MTG-01 게이트 판정 기준, MTG-02 정량 목표, MTG-04 반영 후 이상 감지 기준, MTG-05 canary 승격·중단 조건, MTG-06 진위의 정의 → `docs/meetings/`
