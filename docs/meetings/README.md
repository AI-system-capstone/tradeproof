# 회의록

- 파일 이름: `YYYY-MM-DD-주제.md`
- 「프로젝트 요구사항 최종」의 회의 안건(MTG-01~06)이 결정되면 해당 회의록에 `MTG-xx 결정:`으로 적고, 바뀐 상수는 `common/contracts.py`에 반영합니다.

| 안건 | 내용 | 상태 |
|---|---|---|
| MTG-01 | 게이트 판정 기준 (자동 배포/승인/차단, 허용 미탐·오탐 증가 한도) | 미정 |
| MTG-02 | 정량 목표 (차단율, 처리 시간, Replay 대상 건수) | 미정 |
| MTG-04 | 반영 후 이상 감지 기준 (판정 변경률 정의, 자동 롤백 기준) | 미정 |
| MTG-05 | canary 승격·중단 조건 | 미정 |
| MTG-06 | 진위의 정의 (서명 주체, 기준 해시 출처) | 보류 |
