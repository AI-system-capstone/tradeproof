# B M2 게이트 구현 기준

- 날짜: 2026-11-17
- 근거: B 담당 사용자의 구현 지시. 별도 팀 회의 개최나 전원 합의 완료를 의미하지 않는다.
- MTG-01 결정(B 구현 범위): C가 반환한 골든셋 후보 정확도가 0.90 이상이고 Replay 대상 전체를 처리하면 게이트 합격. 미탐·오탐 증가 한도와 자동 배포 정책은 추가 확정 전까지 임의로 적용하지 않는다. 합격 후 운영자가 배포를 승인하면 B가 D에 배포 요청까지 진행한다. 반려 시 배포하지 않는다.
- 최초 번들: 비교·운영·배포 이력이 없으면 C 비교 검증 없이 운영자의 배포 승인을 받아 D에 요청한다. 이미 운영한 번들의 기준 정보 누락은 이 예외에 포함하지 않는다.
- C 검증 요청: POST /validations를 사용하지 않고 C 이미지의 Kubernetes Job 또는 로컬 Docker 실행으로 요청한다. 후보 등록 후 자동 실행하며 운영 화면에서 별도로 검증을 요청하지 않는다. C는 VALIDATION_CALLBACK_URL로 완료/실패를 통보하고 B는 결과를 폴링하지 않는다. C Job 진입점·콜백 전송은 C 담당자 연동 확인이 필요하다.
- 구현 상수: common/contracts.py의 REGISTRY_GATE_MIN_ACCURACY. 결과의 정확도는 0..1 비율이며 미탐·오탐은 현재 C API 예시의 건수다.
- 영향: B README·OpenAPI·docs/interfaces.md 갱신. contract-change 라벨, A/C/D 담당자 리뷰, 단톡방 공유는 PR 단계에서 필요하다.
